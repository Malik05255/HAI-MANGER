# HAI MANAGER

تطبيق Android عربي لإدارة وفحص راوترات Huawei وZTE بواجهة حديثة ومحرك قابل للتوسع حسب الموديل والـFirmware.

## الرؤية
- اكتشاف الراوتر المتصل تلقائيًا.
- عرض الشركة والموديل وعنوان الإدارة وحالة الاتصال.
- بنية Adapters وFirmware Profiles مستقلة لدعم أجيال متعددة من Huawei وZTE.
- إدارة تحديثات HAI MANAGER وقاعدة تعريفات الأجهزة بشكل منفصل.
- عدم تنفيذ أي عملية حساسة قبل التحقق من التوافق والحصول على موافقة المستخدم.

## IMEI Unlock Lab
- يعمل Offline ولا يرسل IMEI إلى خادم خارجي.
- Huawei legacy: خوارزميات V1 وV2 وV201/3 وFlash مع اختبارات مرجعية.
- ZTE: خوارزمية ZX297520V3 مقيدة بالأجهزة التي تستخدم هذه المنصة فقط.
- TAC resolver يطابق أول 8 أرقام من IMEI قبل اختيار الاستراتيجية؛ الكتالوج المحلي الحالي يحتوي 30 TAC راوتر/CPE موثقة من مصادر عامة.
- TAC معروف يصبح قيد أمان: لا يسمح بسقوط جهاز حديث إلى خوارزمية Legacy لمجرد أن اسم الموديل ناقص أو مختلف.
- Huawei B310/B311/B315 تُعامل كعائلة Balong 4G واعية بقفل V4؛ لا يتم تعميم V1/V2/V201 عليها.
- TAC coverage المضافة تشمل عدة allocations لـB310s، وB311/B311-221، وB315s-22، وE5180، وE5577، وH122-373.
- Huawei B525/B528/B535/B612/B618/B628/B715/B716/B818 وE5186/E5576/E5577 مدرجة ضمن HiLink/4G profiles.
- Huawei H112/H122/H138/H155/H158 وZTE MC801A/MC7010/MC888/MC889/MU5001 تُعامل كأجهزة 5G حديثة ولا تحصل على NCK تخميني من IMEI.
- ZTE MF253/MF283/MF286/MF289/MF297 مدرجة ضمن جيل 4G goform للتشخيص، مع TACات معروفة لـMF286C وMF289F/MF289F Pro وMF297D/MF297D2.
- إذا تعارض اختيار المستخدم للشركة مع شركة TAC المعروفة، يمنع المحرك إنشاء أي نتيجة حتى تصحيح الاختيار.

## سياسة بيانات TAC
- لا يتم إدراج TAC لمجرد ظهوره في منشور مجهول؛ نفضّل قوائم المشغلين الرسمية، أدلة FCC، وكتالوجات TAC المفتوحة ذات المصدر المحدد.
- TAC يعرّف عائلة الجهاز فقط ولا يثبت خوارزمية NCK.
- إضافة TAC جديدة يمكن أن توسع التعرف دون توسيع صلاحيات أو خوارزميات الكتابة.

> الهدف هو زيادة التغطية بدون التضحية بالدقة: إذا لم توجد خوارزمية IMEI-only موثقة لعائلة معينة، يعرض التطبيق التشخيص والمسار المناسب بدل إنشاء كود عشوائي قد يستهلك محاولات NCK.
